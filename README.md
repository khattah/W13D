# W13D - Music Playlist

InnoTech Full Stack Web Development Assignment.

## Description

A Vue 3 application demonstrating component
communication using Props and Emits.

## Components

- SongList
- PlayList
- NowPlaying

## Features

- Display available songs.
- Add songs to a playlist.
- Prevent duplicate songs.
- Select and switch songs.
- Display empty playlist messages.
- Responsive layout.

## Run the project

npm install
npm run dev

## Build

npm run build
